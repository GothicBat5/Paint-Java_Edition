# Fresco : Java Edition

### A 2D Graphics & Digital Painting Application Built with Java

---
Originally started as a personal programming experiment, Fresco has gradually evolved into a project focused on exploring computer graphics, color systems, image processing, and interactive desktop application development.
---

## About the Project

Fresco began around the third quarter of 2025 as a small project created purely for fun and experimentation.

What started as an attempt to build a simple Java paint program has become an ongoing development project. I'm now working toward improving its existing functionality, introducing new tools, and exploring more advanced graphics features.

There is still plenty to build, experiment with, and discover.

**This project is a continuous work in progress... :3**
